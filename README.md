# My_function_IHC
## はじめに

このリポジトリには、Immunohistochemistryのデータ分析とグラフの描画を効率化するためのR自作関数が格納されています。コードを実行すると、自動的にグラフが描画・保存され、解析用のデータセット (csv) が出力されます。Immunohistochemistryにおける切片画像の写真には、 (BZ-X710, Keyence) を用い、解析にはBZ-X analyzer software (Keyence) を用いることを想定しています。(Shimoda

## 概要

この関数は、Immunohistochemistryの膨大なデータ量を解析するのに大幅な時間がかかる課題を解決するために作成しました。

- 特徴1 データの入ったフォルダを選択するだけで、すべてのデータを読み込み、整形したデータを出力します。
- 特徴2 ggplot2ベースのグラフが細胞カウント (Count)、面積 (Area)、輝度 (Luminance)、(赤) 色輝度 (Red Intensity) でそれぞれ描画されるだけでなく、検体ごとの個別データ、ヒストグラムも出力されます。
- 特徴3 引数で自身の好みの描画幅や高さ、線の太さや色等も変更でき、モノクロ出力にも対応しています。

## 使い方
### データセットの用意
STARTLE AND FEAR CONDITIONING Systemで各実験データをxlsファイルに保存する際、群の名前をファイル名に入れてください。例えば、(Shimoda _et al_., 2024) では、安静群をSEDとしているので、○○SED.xlsのようなファイル名にしてください。関数内では、引数として指定した群の名前を用いてデータの分類や群分け、グラフの描画を行います。実験データは、以下のようにそれぞれフォルダ（FC等）にいれ、それをExperiment１等のフォルダに格納してください。
```
├── Experiment1/
    ├── FC/   # 恐怖条件付けの個別データが入ったフォルダ
    ├── Ex1/  # 消去学習一日目の個別データが入ったフォルダ
    └── Ex2/  # 消去学習二日目の個別データが入ったフォルダ
```

筋のサンプリングデータでは、群をGroup、湿重量を筋の名前 (例えばSoleus)、体重をBody_weightと列名をつけてxlsファイル等に保存してください。

### 関数の読み込み

GitHubからスクリプトファイルを読み込むことで、3つの関数、および関数を実行する際に使える文字列のリスト (例: explist = c("FC", "Ex1", "Ex2") がすべて利用可能になります。 

```R
# GitHubから直接スクリプトを読み込む
source("https://raw.githubusercontent.com/RyoShimoda/AUTOGRAPH/main/AUTOGRAPH.R")
```

## 各関数の詳細

###  1. mf_autograph()

| 引数名 | デフォルト値 | 説明 |
| :--- | :---: | ---: |
| `folder_name` | "" | データセットが入っているフォルダ名 |
| `experiment_type`| (必須) | 実験名。FCかEx1もしくはEx2を指定 |
| `path` | (必須) | データセットが入っているフォルダまでのpathを指定 |
| `color` | "" | デフォルトはカラー出力。モノクロ出力の場合は color = "mono"と指定 |
&#8942;

よく使う引数は上記の通りです。使用例の動画では、データセットのフォルダに作業ディレクトリを指定していないため、folder_name = "Demo"と指定し、引数にlegend_position_Ex = "none"をいれて、Ex時のグラフの凡例をなくしていますが、最短コードは以下になります。引数ではその他、群の名前、グラフの各線やテキストの大きさ、色などは個別に指定できます。
```R
# データセットが入っているフォルダを作業ディレクトリにしている場合はfolder_nameも省略可能
# folder_nameで指定したフォルダの下に、グラフ等が格納されるResultsフォルダが生成されます
mf_autograph(experiment_type = "FC,Ex1またはEx2", path = "パス")
```
群の名前は (Shimoda _et al_., 2024) のとおり安静群はSED、低強度運動群はLIE、中強度運動群はMOEとしているので、引数のデフォルトは統制群がSED = "SED"、処理群がLIE  ="LIE"、またはMOE = "MOE"として指定されていますが、群の名前を変える場合は統制群をSED  ="Control"、処理群をLIE = "EXE"等と変更してください。ただ、上記の使用例の箇所でも言及しているとおり、データファイルの名前にその群の名前を入れてください。また、群ごとの色分けも引数で変更可能です。

###  2. mf_sampling()

mf_autograph()とは異なりサンプリングデータはPCから出力されないので、ファイルの自動読み込みはありません。自身で記録したサンプリングのデータファイルを関数に渡し、グラフやデータ分析用のファイルを出力することになります。

| 引数名 | デフォルト値 | 説明 |
| :--- | :---: | ---: |
| `folder_name` | "" | ここで指定したフォルダにResultsフォルダを生成し、グラフを保存 |
| `dataset`| (必須) | データファイルを指定 |
| `sampname` | (必須) | 分析する筋・組織の名称を指定（Adrenal, Thymus, Soleus, Plantaris, Glucose, Lactate) |
| `color` | "" | デフォルトはカラー出力。モノクロ出力の場合は color = "mono"と指定 |
&#8942;

よく使う引数は上記の通りです。mf_autograph()と同様に、群の名前とファイル名の調整が必要になります。引数では、その他グラフのテキストや各線の大きさ、色などを個別に指定することができます。グラフは生成されたResultsフォルダに保存されます。

###  3. mf_FC_annotation()

| 引数名 | デフォルト値 | 説明 |
| :--- | :---: | ---: |
| `folder_name` | "" | ここで指定したフォルダにResultsフォルダを生成し、グラフを保存 |
| `graph`| (必須) | 恐怖条件付けのグラフを指定 |
| `y_first_arrow` | (必須) | 一番左の矢印の先のy位置を指定 |
| `y_second_arrow` | (必須) | 真ん中の矢印の先のy位置を指定 |
| `y_third_arrow` | (必須) | 一番右の矢印の先のy位置を指定 |
| `legend_position_y` | (必須) | ↓:Foot shockテキストの矢印の先のy位置を指定 |
| `color` | "" | デフォルトはカラー出力。モノクロ出力の場合は color = "mono"と指定 |
&#8942;

使用例の動画では、↓:Foot shockの文字列をグラフ下方に表示させるために、legend_position_y = 10、legend_position_x = 4.2で矢印の先のy位置、および矢印のx位置を指定し、legend_text_position = 5で:Foot shockの文字のx位置を指定しています。
